# Support

- Use [GitHub Discussions](https://github.com/P4suta/test-compiler/discussions)
  for usage questions, integration help, and early design ideas.
- Use [GitHub Issues](https://github.com/P4suta/test-compiler/issues) for minimal,
  reproducible bugs and accepted feature proposals.
- Report vulnerabilities only through
  [private security advisories](https://github.com/P4suta/test-compiler/security/advisories/new).

Do not post credentials, proprietary source, or unredacted application values.
This is a community project and does not currently provide an SLA.
