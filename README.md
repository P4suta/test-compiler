# Test-compiler

Find missing assertions and order dependencies in Java and Kotlin tests.

## Installation

```sh
git clone https://github.com/P4suta/test-compiler.git
cd test-compiler
mise install
mise exec -- sh ./gradlew :cli:installDist
```

## Usage

```sh
mise exec -- ./cli/build/install/testc/bin/testc --help
```
